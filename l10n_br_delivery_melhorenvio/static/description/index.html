Melhor Envio Shipping

This module connects the delivery methods to Melhor Envio, the Brazilian shipping platform that sells labels of Correios, Jadlog, Loggi and other carriers.

  • Quotation: one delivery method per Melhor Envio service, each with its own price and estimated delivery time on the sale order and in the shop.
  • Label: the delivery buys the label (cart, checkout paid with the wallet balance, generation and print link). When the sale order has an authorized NF-e, its access key goes with the shipment; otherwise it ships with a content declaration.
  • Tracking: the shipment status feeds the delivery states of the delivery_state module, and the tracking code is filled as soon as Melhor Envio gives it.
  • Cancellation of the label from the delivery.

The Melhor Envio account (OAuth2 application, token and its renewal) is kept in a single record shared by all the delivery methods of its services, and only administrators can read its secrets.

Configuration

  1. At the Melhor Envio panel (sandbox or production), create an application under Integrações > Área Dev. with the redirect URL https://<your odoo>/melhorenvio/oauth/callback.
  2. In Inventory > Configuration > Delivery > Melhor Envio Accounts (administrators only), create an account with the environment, the technical contact e-mail, the Client ID and the Secret, then click Authorize at Melhor Envio. A token generated at the Melhor Envio panel can be pasted in Access Token instead.
  3. Click Synchronize Services: one delivery method is created per service. Archive the services you do not offer and set the box dimensions on the ones you keep.

The quotation uses the weight of the products of the order (at least 50 g) and the ZIP code of the warehouse address as origin. The label needs the street, the city, the ZIP code and the CPF or CNPJ of the warehouse and of the customer.

Usage

  1. On the sale order, Add shipping lists the Melhor Envio services with their prices; pick one.
  2. On the delivery, Buy Melhor Envio Label buys the label and Print Melhor Envio Label opens it. If a step fails after the cart entry is created (for instance when the wallet has no balance), the delivery keeps the Melhor Envio order and the same button resumes it; the order status is read at Melhor Envio first, so a paid label is never paid again.
  3. The scheduled action of delivery_state updates the status and the tracking code. Cancel on the delivery cancels the label at Melhor Envio.

Known issues / Roadmap

  • One volume per package (today the delivery ships in a single box, the one set on the delivery method).
  • Quote each product with its own dimensions.
  • Keep the label PDF as an attachment (today the delivery keeps the public print link).
  • Receipt notice and own hand as options of the delivery method.
  • When the label is bought on validation (Get Rate and Create Shipment), an error raised by another module after the purchase rolls the delivery back: the paid order stays at Melhor Envio and has to be linked by hand.
