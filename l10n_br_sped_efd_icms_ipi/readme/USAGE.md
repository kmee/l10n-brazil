1.  Go to the **SPED > EFD ICMS/IPI** menu and create a declaration for the
    company and period (this is in fact the data of register 0000).
2.  Click **Pull Registers from Odoo** to populate the SPED registers from the
    company transactions in the period.
3.  Click **Generate SPED File** and download the file attached to the chatter.
    Validate it with the official PVA EFD ICMS/IPI before transmitting.
