Volumes da NF-e por lote e por linha de movimento, sobre os volumes da
entrega que o módulo `l10n_br_delivery_nfe` já oferece.

- Assistente **Criar volume**, a partir de uma linha do movimento da entrega:
  sugere os lotes daquela linha e permite incluir lotes de outros produtos.
- Assistente **Adicionar a volume**, a partir de um volume existente.
- Os volumes aparecem em cada linha do movimento e os lotes aparecem em cada
  volume.
- Trava opcional, por tipo de operação de estoque: a entrega só valida quando
  todo lote está dentro de um volume.
