Import NF-e received from suppliers straight into a draft fiscal document,
from an XML file (one, several or a zip) or from the access key.

The window has only two fields: the access key and the upload of files. There
is no preview, grid or intermediate screen. The document is created in draft,
faithful to the XML, with the original XML attached, and the user lands on it
(or on the list of the documents created, with the errors of the files that did
not get in) to review it line by line. The import never creates products,
never learns the supplier de-para, never creates an invoice and never sends a
manifestation event that closes the operation.

Nothing changes for databases that do not install the module: the previous
import wizard stays in the code. Once installed, the NF-e import menu and the
imported documents menu use the new window and list.
