Import NF-e received from suppliers straight into a draft fiscal
document, from an XML file (one, several or a zip) or from the access
key.

The window has only two fields: the access key and the upload of files.
There is no preview, grid or intermediate screen. The document is
created in draft, faithful to the XML, with the original XML attached,
and the user lands on it (or on the list of the documents created, with
the errors of the files that did not get in) to review it line by line.
The import never creates products, never learns the supplier de-para,
never creates an invoice and never sends a manifestation event that
closes the operation.

Nothing changes for databases that do not install the module: the
previous import wizard stays in the code. Once installed, the NF-e
import menu and the imported documents menu use the new window and list.

Usage
=====

**Import files**

1. Open Fiscal > Documents > NF-e > Import.
2. Upload one XML, several, or a zip with them and click Import.
3. A single file opens the document; several files open the list of the
   documents created, and the files that were not imported are reported.

A note already imported for the same company opens the existing
document. A note cancelled or denied (by the protocol of the file or by
the DF-e inbox) is refused, and so is a note whose recipient CNPJ is not
a company of the database. Each note goes to the company of its
recipient CNPJ.

**Import by access key**

1. Open the same window, fill the access key and click Import.
2. If the complete XML is already in the DF-e inbox, the document is
   created.
3. If only the summary is available, the window asks for a confirmation
   to register the acknowledgement of the operation (ciência), which
   releases the XML. That event obliges the company to register the
   final manifestation afterwards. The document is created when the
   complete XML arrives.
4. The acknowledgement is only possible until 10 days after the
   authorization; after that the window asks for the XML file instead.

**Review**

The imported document shows a banner while its lines wait for review,
and the Imported Documents menu has a filter for the documents awaiting
review.

Known issues / Roadmap
======================

- The key import uses the current company as recipient of the DF-e
  query.
- The 10 days of the acknowledgement are counted from the emission date
  kept in the DF-e inbox, which is never later than the authorization
  date.
- Automatic acknowledgement stays the existing company option
  (``auto_manifest_nfe``), off by default.
- Linking with purchases, stock and purchase requests, and the final
  manifestation of the recipient, are left to separate modules.
- Models other than NF-e (CT-e, NFS-e) keep using the previous wizard.
