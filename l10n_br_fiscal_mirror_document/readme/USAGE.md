1. Em **Fiscal > Documentos fiscais**, abra um documento importado (a
   demonstração traz uma NF-e de fornecedor do exterior).
2. Clique em **Criar documento espelho**. O documento da empresa é criado com
   as mesmas linhas e os mesmos impostos. Alterar uma linha do espelho não
   recalcula os impostos. Quando o parceiro não é do Brasil, a origem do ICMS
   das linhas fica como 1 (estrangeira).
3. O botão **Documento original** do espelho abre o original, e o original
   mostra a lista de **Documentos espelho**. O menu **Documentos espelho** lista
   todos.
4. No documento sem fatura, escolha o **Modo de pagamento**. A forma de
   pagamento fiscal do modo vai para o pagamento da NF-e (`detPag`).
