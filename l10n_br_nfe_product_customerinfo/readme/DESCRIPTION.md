Leva para a NF-e o código e o nome que o cliente usa para o produto.

A linha fiscal ganha os campos *Código do Produto do Parceiro (cProd)* e *Nome do Produto do
Parceiro (xProd)*. Quando preenchidos, saem no XML no lugar da referência interna e do nome
do produto. Na venda e na remessa (movimento de estoque) os campos são preenchidos a partir do
cadastro de produto do cliente do módulo `product_customerinfo`.
